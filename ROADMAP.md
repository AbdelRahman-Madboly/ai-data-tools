# Roadmap — ai-data-tools

Done = I can load, clean, transform, and visualize a real dataset and build a
full scikit-learn pipeline without googling the API.
Each topic is tracked honestly in [`_plan/PROGRESS.md`](_plan/PROGRESS.md).

Starts after `codebricks-python` v1.0.0.

| Library      | Topic |
|--------------|-------|
| NumPy        | arrays, broadcasting, vectorization, indexing, linear algebra ops |
| Pandas       | DataFrame, Series, groupby, merge, pivot, data cleaning |
| Matplotlib   | line, scatter, bar, histogram, subplots, customization |
| scikit-learn | preprocessing, pipelines, model selection, evaluation metrics |

**v1.0.0** ships when the toolkit is second nature.
